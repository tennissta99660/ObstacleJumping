# ObstacleJumping
A simple yet fun infinite running game where the player must jump over incoming obstacles while running forward. The game features engaging sound effects and a background soundtrack to enhance the experience.

## 🎮 Features
- **Endless Running** – The player moves continuously forward, dodging obstacles.
- **Jump Mechanic** – Time your jumps perfectly to avoid collisions(by pressing spacebar).
- **Sound Effects** – Unique sounds for jumping and dying.
- **Background Music** – A continuous soundtrack to set the mood.

## 🎮 How to Play
- **Jump:** Press `Space` or `Up Arrow` to make the player jump.
- **Avoid Obstacles:** Time your jumps correctly to dodge obstacles.
- **Survive:** The game ends if you collide with an obstacle.

## 🔥 Technologies Used
- **Unity** – Game engine
- **C#** – Game logic and mechanics
- **Audio Engine** – Handles sound effects and background music

## 📌 Future Improvements
- Add different obstacle types.
- Introduce power-ups for extra abilities.
- Implement difficulty scaling over time.
